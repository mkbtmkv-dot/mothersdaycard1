The Goal: Build a Mother's Day card generator where the backend "Bot" handles all cropping, rotation, and layering automatically. The final output must be 1080x1920.

1. The "Bot" Processing Logic (Sharp/Node.js):
Every uploaded photo must pass through this exact Strict Buffer pipeline before being placed on the template:

Fix Orientation: Use .rotate() first to read EXIF data (fixes tilted phone uploads).

Universal Scaling: Use .resize(width, height, { fit: 'cover', position: 'attention' }). This ensures any image size or aspect ratio fills the slot perfectly with no stretching or gaps.

Visual Polish: Apply .modulate({ saturation: 1.15, brightness: 1.05 }).

Slot Rotation: If a slot is tilted, the photo buffer must be rotated by that exact degree before it is layered onto the template.

2. The Assembly Order (Crucial for JPEGs):
Since the templates (image_1.jpg to image_5.jpg) are JPEGs, do not attempt to place photos "behind" them. Use this order:

Base: The Template JPEG.

Top: The processed and tilted User Photo(s).

Overlay: The transparent SVG for the mother’s name (at y=1780, text-anchor="middle", fill="#4A3728").
